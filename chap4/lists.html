Important Points

  • C: Procedural, fast, low-level memory control, pointers, widely used for system programming.
  • C++: Object-oriented extension of C, supports classes, inheritance, polymorphism, STL.
  • Java: Object-oriented, platform-independent, JVM-based, widely used for application development.
  • Python: High-level, interpreted, easy syntax, dynamically typed, widely used in AI/ML, data science and web development.

Definitions

Programming Language:
A formal language used to give instructions to a computer.
Compiler:
A program that translates the entire source code into machine/object code before execution.
Interpreter:
A program that translates and executes code line by line.
Syntax:
The set of rules that defines how a program must be written.
Semantics:
The meaning of statements and instructions in a programming language.
Variable:
A named memory location used to store a value.
Data Type:
Specifies the type of data that a variable can store.
Function:
A reusable block of code designed to perform a specific task.
Object-Oriented Programming (OOP):
A programming approach based on objects and classes.
Algorithm:
A step-by-step procedure for solving a problem.
